智趣通物聯 网站交付包

公开网站
https://funconnect-hong-kong.pages.dev/

页面
- index.html：首页
- project.html：AIoT Project 创作技巧
- product.html：产品与报价
- contact.html：联系页面

部署方法
1. 将本文件夹内的全部文件和 assets 文件夹原样上传至静态网站主目录。
2. 保持目录结构不变。
3. 将默认入口设置为 index.html。

作品集版本
- 为保护隐私，电话号码、即时通讯链接和联系表单已移除。

注意
- assets 文件夹为网站必要资源，请勿删除或改名。
- 本包不包含内部设计记录、原始 PPTX、重复图片和审查文档。
